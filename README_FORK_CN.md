# KISS Translator Fork - 新增功能说明

本分支为 KISS Translator 添加了以下新功能：

## 新增功能

### 1. 查词历史功能

自动记录用户使用划词翻译的历史记录，并与收藏词汇合并到一个统一的"词汇管理"页面中。

**功能特性：**
- 自动记录每次划词翻译的原文、译文、翻译服务
- 支持搜索历史记录
- 支持导入/导出历史记录（CSV、TXT、Markdown 格式）
- 可在设置中开启/关闭查词历史
- 可自定义历史记录保存数量（1-100000 条）
- 去重处理：相同文本忽略大小写去重，只保留最新的一条记录
- 批量删除功能：支持多选删除，支持一键全选
- **折叠面板展开显示：** 点击展开图标可查看详细信息和词典释义
- **词典释义集成：** 展开时自动调用词典 API 显示单词的释义、音标、例句
- **多格式导出释义：** 导出时可选择包含词典释义的 TXT、CSV、MD 格式

**使用方法：**
1. 点击扩展图标打开设置
2. 在左侧菜单中选择"收藏词汇"
3. 通过顶部 Tab 切换到"查词历史"标签页
4. 点击历史记录项的展开图标查看详细信息和词典释义
5. 可以查看、搜索、导出或批量删除历史记录

**设置选项：**
- 在"基本设置"页面可以配置：
  - 启用/禁用查词历史
  - 设置历史记录最大数量（默认 50 条，范围 1-100000 条）

**导出格式说明：**
- **导出（CSV）**：简单格式，包含原文、译文、服务、时间四列
- **导出（TXT）**：详细格式，包含查词历史信息及词典释义，适合阅读
- **导出（CSV）- 含释义**：结构化数据，包含所有字段和词典释义，支持 Excel 打开
- **导出（MD）- 含释义**：Markdown 格式，适合文档分享，保留词典的详细注释

**实现细节：**
- 新增 `src/hooks/LookupHistory.js` - 查词历史管理 Hook
- 新增 `src/views/Options/WordsPage.js` - 收藏词汇与查词历史合并页面
- 新增 `src/config/storage.js` 中的 `STOKEY_LOOKUP_HISTORY` 存储键
- 修改 `src/views/Selection/TranCont.js` 在翻译完成时自动保存历史
- 添加路由配置，使用统一的"词汇管理"页面
- 添加多语言 i18n 支持
- **增强 `src/views/Options/FavWords.js`：**
  - 为 HistoryAccordion 添加折叠面板展开/收起功能
  - 集成词典 API 调用，展开时显示单词释义
  - 新增查词历史导出功能（TXT、CSV、MD 格式）
  - 导出时实时调用词典 API 获取释义

### 2. CTRL+选中触发模式

新增了一个触发模式，可以在以下条件下触发翻译：
- 选中文本 AND
- 按住 CTRL 键

可以在扩展设置中选择此触发模式：设置 → 划词翻译 → 触发方式 → CTRL+选中触发

**实现细节：**
- 在 `src/config/setting.js` 中添加了新常量 `OPT_TRANBOX_TRIGGER_CTRL_SELECT`
- 添加到可用触发模式数组 `OPT_TRANBOX_TRIGGER_ALL`
- 为所有支持的语言添加了 i18n 翻译
- 更新了鼠标松开事件处理器，在 CTRL+选中模式下检查 `e.ctrlKey`

### 3. 弹出窗口默认显示翻译标签页

点击工具栏扩展图标时，弹出窗口现在默认显示翻译标签页，而不是设置标签页。

**实现细节：**
- 在 `src/views/Popup/index.js` 中将 `showTrantab` 的初始状态从 `false` 改为 `true`

## 安装说明

### 在 Chrome 中加载扩展

1. 下载构建好的扩展包（在仓库根目录查找 `build/chrome` 文件夹）
2. 或者从构建产物中解压 zip 文件
3. 打开 Chrome 浏览器，访问 `chrome://extensions/`
4. 在右上角启用"开发者模式"
5. 点击"加载已解压的扩展程序"按钮
6. 选择解压后的 `chrome` 文件夹
7. 扩展现在应该已安装并激活

### 使用查词历史功能

1. 使用划词翻译功能翻译任意文本
2. 历史记录会自动保存（设置中启用时）
3. 点击扩展图标 → 收藏词汇 → 切换到"查词历史"标签页
4. 可通过搜索框查找特定记录（按原文或译文搜索）
5. 点击历史记录项的展开图标查看详细信息和词典释义
6. 可通过复选框多选记录，然后点击"删除选中"批量删除
7. 点击"全选"按钮可快速选择所有可见项目
8. 支持四种导出格式：
   - 导出（CSV）：简单格式，仅包含基础信息
   - 导出（TXT）：详细格式，包含词典释义
   - 导出（CSV）- 含释义：结构化数据，包含词典释义
   - 导出（MD）- 含释义：Markdown 格式，适合文档分享

### 使用 CTRL+选中触发功能

1. 点击扩展图标打开设置
2. 切换到设置标签页（点击顶部的齿轮图标）
3. 找到"划词翻译"部分
4. 在"触发方式"下拉菜单中选择"CTRL+选中触发"
5. 设置会自动保存
6. 现在，当你在任何网页上选中文本并同时按住 CTRL 键时，翻译将自动显示

## 从源码构建

如需从源码构建扩展：

```bash
# 安装依赖
pnpm install

# 构建 Chrome 扩展
pnpm build:chrome

# 构建的扩展将位于 build/chrome/ 目录
```

这些更改遵循最小化改动的设计原则：

- 功能清晰分离

## 页面说明

### 收藏词汇与查词历史页面 (WordsPage)

这是一个统一的词汇管理页面，通过 Tab 切换两个子页面：

#### 收藏词汇标签页
- 显示所有收藏的单词
- 支持字典和建议查询
- 支持 YouTube 字幕时间跳转
- 支持导入/导出（TXT、CSV、MD 格式）
- 支持批量删除收藏词汇

#### 查词历史标签页
- 显示所有翻译历史记录
- 显示原文、译文、翻译服务、时间
- 支持点击展开查看详细信息和词典释义
- 展开时显示词典的读音、释义、例句等内容
- 支持搜索（按原文或译文）
- 支持四种导出格式：
  - CSV（简单）：仅包含原文、译文、服务、时间
  - TXT（详细）：包含查词历史及词典释义
  - CSV（详细）：包含所有字段和词典释义，支持 Excel
  - MD（详细）：Markdown 格式，适合文档分享
- 支持批量删除历史记录

#### 通用功能（两个标签页共享）
- 搜索栏：实时过滤显示内容
- 全选按钮：一键选中所有可见项
- 批量删除：删除选中的项目，显示选中数量
- 清空全部：清空当前标签页的所有数据

## 构建产物

- 构建的 Chrome 扩展包大小：约 1.2MB
- 包含所有必需的文件和本地化资源
- 可直接在 Chrome 或基于 Chromium 的浏览器中安装使用

## 注意事项

- 这些更改与上游仓库兼容，方便后续同步上游更新
- 所有新功能都是可选的，不影响现有功能
- 代码遵循项目现有的代码风格和架构
- 查词历史默认启用，可在设置中关闭
- 历史记录去重不区分大小写，同一文本只保留最新记录
- 列表项通过复选框选择，避免与折叠面板的展开/收起冲突
- 查词历史展开时会调用词典 API 显示释义，需要有网络连接
- 导出查词历史时会实时调用词典 API，导出时间取决于历史记录数量和网络状况
- 所有导出格式都包含 BOM 头（UTF-8），确保在 Excel 中正确显示中文
